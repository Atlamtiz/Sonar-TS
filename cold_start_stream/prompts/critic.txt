# REVIEW AXES

1. Framework fit — tables, columns, globals and the `_result` shape are exactly
   those above. Flag any invented table, column or input.
2. Correctness — would the algorithm give the expected answers for the example
   cases? Walk through at least one failed case step by step.
3. Specificity — operations, granularities, thresholds and ranking keys are
   concrete. No "handle appropriately".
4. Edge cases — empty candidate sets, short histories, window boundaries, ties,
   NaNs, sampling steps other than the examples'.
5. Generality — every quantity a question supplies is a placeholder read from the
   question. Flag ANY hard-coded channel id, year, date, result count, threshold
   or length that a question would state, and ANY statement about what the data
   or the answers "usually" look like.
6. Routability — the description says, in terms of what the user asks for, when
   to use the skill and when not to, and does not overlap the other descriptions
   in the manifest.
7. Symbolic index — if the questions are about the FORM of ONE curve (a shape, a
   trend pattern, calm vs. volatile stretches), the algorithm AND the snippet
   must begin with a pattern search on the symbolic column of a feature table,
   built by a general rule from the words of the question in the codebook's
   terms; the table's token length must fit the time scale of the shape; the
   pattern must be loose enough not to lose true answers, must encode exactly
   what the codebook says the symbols express (no more, no less), and must let a
   flat part sit at any level; verification and ranking happen on raw_data for
   the shortlist only; there is a fallback when the shortlist is empty or too
   short. A draft for such questions without a symbolic search is a FIX. A
   literal index string copied from an example is a FIX. For questions that are
   NOT about form (a statistic, a threshold, a fixed-length window, a cycle
   length, a reference pattern, two series, a historical level, a report), a
   forced symbolic search is a FIX.
7b. Ranking key — for ranked-list answers the skill names the quantity and the
   part of the window it is measured on, computes it on raw data, and breaks
   ties deterministically. A ranking by a quantity the question did not ask for
   (whole-day range for a question about one segment) is a FIX.
8. Complete and compact — the code fence is closed and the snippet is valid
   Python once placeholders are filled; the document is under about 900 words
   plus one snippet of at most 80 lines; it does not pile special cases on top
   of each other; it never refers to another skill by name.
9. Consistency — the snippet does exactly what Algorithm and Rules say. Flag every
   contradiction between prose and code (a pattern the Rules forbid but the code
   uses, a ranking key described one way and computed another).
